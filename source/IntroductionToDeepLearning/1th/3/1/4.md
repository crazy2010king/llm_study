# Sigmoid 函数全面讲解：把"天书公式"拆成积木

这一页出自《深度学习入门》第 3 章"神经网络"的 3.2 节"激活函数"，主角是 **sigmoid 函数**。下面我把这一页的每一句话、每一个符号、公式的每一步来龙去脉，全部拆开讲透。

---

## 一、先搞懂背景：这页书在讲什么位置的知识？

### 1. 回顾上一章：感知机的"老规矩"

上一章的感知机是这样工作的：

```
把输入信号 × 权重，全部加起来，得到"总分"
如果 总分 > 阈值 → 输出 1（神经元被激活）
如果 总分 ≤ 阈值 → 输出 0（神经元沉默）
```

这个"超过阈值就突然从 0 跳到 1"的规则，就是页脚注释①说的：

> **阶跃函数：一旦输入超过阈值，就切换输出的函数。**

**类比：** 阶跃函数就像一个**老式电灯开关**——只有"开"和"关"两个档位，"啪"一下切换，没有中间状态。

### 2. 这一页要说的新事情

书上说：**神经网络和感知机的主要区别，就在于把这个"激活函数"从阶跃函数换成了 sigmoid 函数。** 其他地方——神经元怎么分层连接、信号怎么一层层传递——都和感知机基本一样。

**类比：** 还是那条工厂流水线，还是那些工人，唯一的改变是：**最后一道质检员的评判方式变了**——以前他只会喊"合格/不合格"（阶跃函数），现在他改打分数了："合格度 73%"、"合格度 88%"（sigmoid 函数）。

所以读懂这一页的关键，就是读懂这个新的"打分规则"：

$$h(x) = \frac{1}{1+\exp(-x)}$$

## 二、拆除心理障碍：函数 = 转换器

书上原话："函数就是给定某个输入后，会返回某个输出的转换器。"

**类比：豆浆机。** 你扔进去豆子（输入），它倒出来豆浆（输出）。机器内部的规则是固定的，你不用管它里面怎么磨怎么煮，只需要知道"扔进什么、出来什么"。

所以 `h(1.0) = 0.731…` 这句话翻译成人话就是：

> "往 sigmoid 这台机器里扔进 1.0，它吐出 0.731。"

公式长得再复杂，它也只是一台**加工数字的机器**。下面我们把这台机器打开，看看里面的三个车间。

## 三、认识配角：e 和 exp(−x)

### 1. e 是什么？（纳皮尔常数 2.7182…）

e 和圆周率 π≈3.14159 一样，就是一个**固定的常数**，约等于 2.71828。它不是谁拍脑袋定的，而是从"连续增长"中自然长出来的。

**推导 e 是怎么来的（复利类比）：**

假设银行年利率 100%，你存 1 元钱，利息可以反复"利滚利"：

| 结算方式 | 计算 | 年末本息 |
|---|---|---|
| 一年结算 1 次 | (1+1)¹ | 2 元 |
| 一年结算 2 次（每次 50%） | (1+0.5)² | 2.25 元 |
| 一年结算 12 次 | (1+1/12)¹² | ≈2.613 元 |
| 一年结算 365 次 | (1+1/365)³⁶⁵ | ≈2.715 元 |
| **每时每刻连续结算** | 极限 | **≈2.71828 元 = e** |

你会发现：结算越频繁，钱越多，但**不会无限涨**，而是逼近一个天花板——这个天花板就是 e。所以 e 又叫"自然常数"，凡是涉及**连续增长、连续衰减**的地方（细菌繁殖、放射性衰变、咖啡冷却），都会冒出 e。

### 2. exp(−x) 是什么？

`exp(−x)` 只是一种写法，意思就是 **e 的 −x 次方**，即：

$$\exp(-x) = e^{-x} = \frac{1}{e^{x}}$$

它的"脾气"只有三条，记住就够：

- **x = 0 时**：e⁰ = 1（任何数的 0 次方都是 1）
- **x 是正数且越大**：e⁻ˣ 越小，一路缩小逼近 0
- **x 是负数且越负**：e⁻ˣ 越大，爆炸式增长

**类比：一杯热咖啡的冷却。** 咖啡和室温的温差就像 e⁻ˣ——时间 x 越久，温差越小，最后几乎为 0；而且它是"平滑地"越来越慢地降温，不会突然跳变。

几个常用数值（建议记住感觉）：

| x | exp(−x) |
|---|---|
| −2 | ≈7.389 |
| −1 | ≈2.718 |
| 0 | 1 |
| 1 | ≈0.368 |
| 2 | ≈0.135 |
| 5 | ≈0.0067 |
| 10 | ≈0.000045 |

## 四、推导（上）：一步一步"组装"出 sigmoid 公式

很多人以为这个公式是天上掉下来的，其实它是被**设计**出来的。设计目标有三个：

1. 不管输入多大或多小，输出都要被**压缩到 0 和 1 之间**；
2. 变化要**平滑**，不能跳；
3. 输入很大时输出接近 1，输入很小时输出接近 0，输入为 0 时输出正好 0.5。

下面三步组装，就是公式的"诞生过程"：

**第 1 步：先拿出 exp(−x)。**
它的取值范围是 (0, +∞)——永远为正，但可能大到无穷，不符合目标 1。

**第 2 步：给它加 1，得到 1 + exp(−x)。**
取值范围变成 (1, +∞)。加 1 有两个妙处：
- 保证分母**永远大于 1，绝不会是 0**（除以 0 会让机器崩溃）；
- 为下一步取倒数做好铺垫。

**第 3 步：取倒数，得到 1 ÷ (1 + exp(−x))。**
这是最关键的一步。回忆小学知识：**分子固定是 1，分母越大，结果越小。**

- 当 x 非常大：exp(−x)≈0 → 分母≈1 → 结果≈1/1 = **接近 1** ✔
- 当 x 非常负：exp(−x) 巨大 → 分母巨大 → 结果≈1/巨大 = **接近 0** ✔
- 当 x = 0：分母 = 1+1 = 2 → 结果 = **正好 0.5** ✔

三步做完，一个"无论输入多么狂野，输出都乖乖落在 0~1 之间、而且平滑过渡"的函数就诞生了——这就是 sigmoid 公式。**公式里的每个零件都有分工：exp 负责感知输入大小，+1 负责保底防崩溃，取倒数负责把范围压进 (0,1)。**

**类比：稳压器/变压器。** 不管外面电压是 1 万伏还是 0.001 伏，经过它之后，输出永远稳定在 0~1 伏之间的安全范围。

## 五、推导（下）：手算验证，复现书上的数字

### 手算 h(1.0)

```
第1步：x = 1.0
第2步：exp(−1.0) = 1/e ≈ 1 ÷ 2.71828 ≈ 0.3679
第3步：1 + 0.3679 = 1.3679
第4步：1 ÷ 1.3679 ≈ 0.731
```
✅ 与书上的 h(1.0) = 0.731… 完全一致。

### 手算 h(2.0)

```
第1步：x = 2.0
第2步：exp(−2.0) = 1/e² ≈ 1 ÷ 7.389 ≈ 0.1353
第3步：1 + 0.1353 = 1.1353
第4步：1 ÷ 1.1353 ≈ 0.8808
```
✅ 与书上的 h(2.0) = 0.880… 完全一致。

### 再多算几个，建立直觉

| 输入 x | 计算过程 | 输出 h(x) |
|---|---|---|
| −10 | 1÷(1+22026) | ≈0.00005（几乎 0） |
| −1 | 1÷(1+2.718) | ≈0.269 |
| 0 | 1÷(1+1) | **0.5（正中间）** |
| 1 | 1÷1.3679 | ≈0.731 |
| 2 | 1÷1.1353 | ≈0.880 |
| 10 | 1÷1.000045 | ≈0.99995（几乎 1） |

从表里能看出三件事：
1. **输出永远在 0 和 1 之间**，从不越界；
2. **输入为正输出就大于 0.5，输入为负就小于 0.5**，0 是分界点；
3. 有一个漂亮的对称性：h(−x) = 1 − h(x)（比如 0.269 = 1 − 0.731）。

把这些点连成线，就是一条平缓的 **S 形曲线**——"sigmoid"这个名字就是"S 形"的意思。

## 六、推导（进阶选读）：公式还能从"概率"严格推出来

> 这一节是给想追根究底的人的彩蛋，看不懂完全可以跳过，不影响理解。

如果我们希望神经元输出一个"概率/把握程度" p（必然在 0~1 之间），可以这样推：

```
第1步：把概率换成"赔率"：p/(1−p)，它的范围是 0 ~ +∞
第2步：取对数，得到"对数赔率" ln(p/(1−p))，范围变成 −∞ ~ +∞
第3步：令对数赔率等于输入 x：  ln(p/(1−p)) = x
第4步：两边取 e：              p/(1−p) = eˣ
第5步：交叉相乘：              p = eˣ(1−p) = eˣ − p·eˣ
第6步：把含 p 的项移到一边：    p(1+eˣ) = eˣ
第7步：解出 p：                p = eˣ/(1+eˣ)
第8步：分子分母同除以 eˣ：     p = 1/(1+e⁻ˣ)   ✅
```

看，最后一步得到的正是 sigmoid 公式！这说明它不是随便凑的，而是**"把输入 x 解释为对数赔率时，唯一对应的概率函数"**。这也是它又叫"逻辑斯谛函数（logistic function）"的原因。

## 七、与阶跃函数对比：这一页真正的核心

书上说："下面，让我们通过和阶跃函数的比较来详细学习 sigmoid 函数。"

**相同点：** 两者都是"输入很小→输出接近 0；输入很大→输出接近 1"，都是在做"要不要激活"的判断。

**不同点：**

| | 阶跃函数（感知机用） | sigmoid（神经网络用） |
|---|---|---|
| 输出 | 只有 0 或 1 | 0~1 之间任意小数 |
| 变化方式 | 到阈值"啪"地跳变 | 平滑、连续地过渡 |
| 类比 | 老式电灯开关：只有开/关 | 调光旋钮：可以调到 73% 亮度 |
| 回答风格 | "是！"或"否！" | "我有 73.1% 的把握是" |

### 为什么"平滑"这么重要？

**类比 1：调洗澡水。** 如果水龙头是阶跃式的——往左拧一点是滚烫，往右拧一点是冰凉——你永远调不出舒服的水温。而平滑的旋钮"拧一点、变一点"，你才能一点点微调到位。

**类比 2：蒙眼下山。** 神经网络"学习"的本质，是不断微调权重，让错误越来越小，就像蒙着眼睛下山，全靠脚底感觉坡度往低处挪。阶跃函数是一座**悬崖**：崖顶崖底都是平的（坡度为 0），边缘又垂直，你的脚感受不到任何有用的坡度，永远不知道怎么挪步。而 sigmoid 是一座**平缓的小山丘**，处处都有坡度，每挪一步都知道方向和大小，才能顺利走到谷底。

（用术语说就是：平滑→可导→能用梯度下降法自动学习。这正是后面章节的伏笔。）

## 八、这一页的本质，一句话总结

> **神经网络 = 感知机原来的身体（多层神经元、信号层层传递）+ 一颗新的心脏（sigmoid 激活函数）。**

换心之后，信号的含义升级了：

- 感知机里，信号是**电报**：要么"滴"（1），要么不响（0）；
- 神经网络里，信号是**带刻度的音量**：0.731 表示"七成三地激活"，信息量大得多；

但信号的**流动方式没变**：上一层神经元算完、转换完，再传给下一层——就像流水线，只是现在工人之间传递的不再是"过/不过"，而是一个"程度值"。

## 九、速记小抄

| 要点 | 内容 |
|---|---|
| 公式 | h(x) = 1 / (1 + e⁻ˣ) |
| e | 自然常数≈2.71828，连续复利增长的天花板 |
| exp(−x) | x 越大它越接近 0，x 越负它越大 |
| 公式三步组装 | exp(−x) 感知大小 → +1 保底 → 取倒数压进 (0,1) |
| h(0) | 0.5（对称中心） |
| 输出范围 | 永远在 (0, 1) 之间 |
| 对比阶跃函数 | 把"开关"换成了"调光旋钮"：平滑、连续 |
| 最大意义 | 平滑→可微调→神经网络能"学习" |

记住一句话就够了：**sigmoid 就是把感知机那个"啪嗒一声的开关"，换成了一枚"可以无级调节的旋钮"——而这个小小的改变，正是通向深度学习的大门。**
