# 九、构造概率比例

假设：

有两个竞争力量：

正向：

[
e^x
]

负向：

[
1
]

总量：

[

]

那么：

正向比例：

[
\frac{e^x}{1+e^x}
]

这个范围：

0~1。

---

但是 sigmoid 通常写：

[
\frac{1}{1+e^{-x}}
]

---

# 十、数学变形得到 sigmoid

从：

[
\frac{e^x}{1+e^x}
]

上下同时除以：

[
e^x
]

分子：

[
\frac{e^x}{e^x}=1
]

分母：

[
\frac{1+e^x}{e^x}
]

得到：

[
\frac1{\frac1{e^x}+1}
]

因为：

[
\frac1{e^x}=e^{-x}
]

所以：

# [

\frac1{1+e^{-x}}
]

这就是：

[
\boxed{
h(x)=\frac1{1+e^{-x}}
}
]

---

# 十一、为什么输入1得到0.731？

图片：

[
h(1)=0.731
]

我们计算。

公式：

[
h(x)=\frac1{1+e^{-x}}
]

代入：

x=1

得到：

[
h(1)=
\frac1{1+e^{-1}}
]

---

因为：

[
e^{-1}
======

\frac1e
]

而：

[
e=2.718
]

所以：

[
e^{-1}=0.3679
]

于是：

[
h(1)
====

\frac1{1+0.3679}
]

分母：

[
1.3679
]

所以：

[
h(1)
====

0.731
]

---

# 十二、为什么输入2得到0.880？

所以：

]

结果：

[
=0.880

[

# 十九、但是今天为什么不用 sigmoid 作为隐藏层？

这是深度学习历史的重要知识。

sigmoid 有两个问题。

---

## 问题1：梯度消失

当：

输入很大：

例如：

x=10

sigmoid：

接近：

1

变化非常小。

导数：

接近0。

网络前面的层：

学不到东西。

---

## 问题2：计算慢

需要：

指数：

[
e^x
]

硬件计算成本较高。

---

所以后来：

隐藏层大量使用：

ReLU。

公式：

[
f(x)=max(0,x)
]

简单：

```
负数=0

正数保持
```

---

但是：

输出层：

分类概率：

仍然经常使用：

sigmoid。

---

# 二十、总结：一句话理解 sigmoid

> sigmoid 是一种把神经元计算出的任意大小的“评分”，压缩到0和1之间的S型函数，它让神经网络从简单的“开关判断”变成可以连续学习、逐渐调整的智能系统，是传统感知机走向现代神经网络的关键桥梁。
